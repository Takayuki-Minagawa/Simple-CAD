## 2. 方針決定（仕様確認が必要だった項目）

| ID | 決定 | 理由 |
|---|---|---|
| R01 | **入力単位は mm 固定を維持**し、セレクターを「表示単位」に改名。座標欄・動的入力・プロパティに「入力: mm」を常時表示。加えて座標入力で `2m,2m` / `@2.5m<0` / `2000mm` の**単位サフィックス**を受け付ける | データ正本・CLI・Python 移植が mm 前提（ヘルプにも「単位は mm 固定」と明記）。表示単位に入力を連動させると回転・線幅・透過率など非長さ欄との整合が崩れる。サフィックスにより m 入力の意図を明示的に伝えられる |
| R08 | 「長さ」を **平面長 (XY)** に改名し、線材には **3D部材長 (XYZ)** と **Z差** を併記 | 既存値は XY 投影長で正しい。名称で区別し、鉛直柱は 3D 部材長 3000mm と読める |
| R09 | 「端部編集」ダイアログを新設（編集メニュー）。対象 ID・端（始点/終点）・基準部材 ID を指定し、適用前に変更後座標と長さをプレビュー。既存のクリック操作は維持 | クリック依存を無くし、同条件で再現可能にする |
| R10 | 3D ツールバーに 上面 / 正面 / 右側面 / 等角 / 全体表示 / 選択表示 の名前付きボタンと「視点: ○○ / 投影: ○○」の文字表示を追加 | ギズモは drei 製でアクセシビリティツリーに現れないため、別途名前付き操作を用意 |
| R07 | 900px 以下では直接ツールボタン群を隠し「現在のツール」チップを表示（ツール自体は「作図」メニューに全て存在）。ステータスバーは折り返し＋「簡易/詳細」切替。右パネル重ね表示に閉じるボタンを付ける。推奨幅 1024px 以上を README に明記 | 要望の受入基準に合わせる |
